Source: https://roapp.readme.io/reference/assets

```APIDOC
## GET /warehouse/assets

### Description
Get the list of Assets. Supports filtering by asset IDs, serial numbers (UIDs), warehouse IDs, and owner IDs.

### Method
GET

### Endpoint
https://api.roapp.io/warehouse/assets

### Parameters
#### Query Parameters
- **ids[]** (array of int32s) - Optional - Assets id
- **uid[]** (array of strings) - Optional - Serial numbers of assets (VIN, IMEI)
- **warehouse_id[]** (array of int32s) - Optional - Warehouses ID
- **owner_id[]** (array of int32s) - Optional - Assets owners ID

### Get Assets API Request (PHP)

Source: https://roapp.readme.io/reference/assets

Example PHP code to fetch assets using the roapp.io API. This snippet utilizes cURL functions to perform the GET request and retrieve the JSON response.

```php
<?php

$ch = curl_init();

curl_setopt($ch, CURLOPT_URL, 'https://api.roapp.io/warehouse/assets');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
curl_setopt($ch, CURLOPT_CUSTOMREQUEST, 'GET');
curl_setopt($ch, CURLOPT_HTTPHEADER, array('accept: application/json'));

$response = curl_exec($ch);

if (curl_errno($ch)) {
    echo 'Error:' . curl_error($ch);
} else {
    echo $response;
}

curl_close($ch);
?>
```
